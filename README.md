# Прогнозирование цен на автомобили (Курсовая работа, Вариант 2)

**Автор:** Груздев Андрей Александрович (гр. Б.ПИН.ИИ.25.16, ТвГТУ)  
**Тема:** Разработка приложения на языке программирования Python для прогнозирования цен на автомобили.

---

## Структура проекта

- `src/` — исходный код приложения:
  - `src/config/` — пути, метаданные, признаки, пресеты автомобилей, эталонные метрики Loginom.
  - `src/data/` — загрузка, очистка марок/признаков, валидация и предобработка данных (`CarDataPreprocessor`).
  - `src/models/` — обучение 4 моделей регрессии (`Random Forest`, `Ridge`, `MLP`, `KNN`), инференс (`ModelService`), расчет доверительных интервалов и рыночной сегментации.
  - `src/analytics/` — построение EDA-графиков и OLAP-срезов.
  - `src/storage/` — локальная база данных SQLite (`predictions.db`) для истории прогнозов.
  - `src/gui/` — графический интерфейс пользователя на `CustomTkinter` (вкладки прогнозирования, OLAP-аналитики, пресетов и справки).
- `tests/` — модульные тесты (`pytest`).
- `data/` — датасет `CarPrice_Assignment.csv`, предобработанный датасет и словарь признаков.
- `models/` — обученные модели (`.joblib`), препроцессор и `metadata.json`.
- `reports/` — метрики моделей (`metrics.json`) и графики (`reports/figures/`).
- `loginom/` — аналитический сценарий для платформы Loginom Community 7.4.2 (см. [loginom/README.md](loginom/README.md)).
- `images/`, `screenshots/` — графики, схемы и скриншоты интерфейса.
- `transformer/` — генератор пояснительной записки в формате `.docx` по ГОСТ.
- `train_models.py` — полный цикл подготовки данных, построения графиков и обучения моделей.
- `run_gui.py` — точка входа для запуска Desktop-приложения.
- `create_retro_presentation.py` — скрипт генерации презентации `Презентация_Груздев_А_А.pptx`.
- `Пояснительная_записка_Груздев_А_А.docx`, `Презентация_Груздев_А_А.pptx` — итоговые материалы курсовой работы.

## Быстрый старт

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Обучение моделей и генерация графиков:**
   ```bash
   python train_models.py
   ```

3. **Запуск графического интерфейса (GUI):**
   ```bash
   python run_gui.py
   ```

4. **Запуск тестов:**
   ```bash
   python -m pytest
   ```
