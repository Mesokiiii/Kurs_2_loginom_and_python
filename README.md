## Ключевые возможности (v2.2)

- **4 версионированные модели ML (`v2.2`)** с отображением метрик качества в скобках (`R²` и ошибки `MAPE` на отложенной тестовой выборке):
  - **Случайный лес (`Random Forest v2.2`)** — лидер (`R² тест = 0,9582`, `R² обуч. = 0,9853`, `MAE = 117,1 тыс. руб.`, `RMSE = 169,8 тыс. руб.`, `MAPE = 9,14%`, 85,4% авто попадают в коридор ±15%).
  - **Гребневая регрессия (`Ridge v2.2`, `alpha = 1,5`)** — обучена на 164 авто (80% выборки, 69 признаков после One-Hot кодирования и `StandardScaler`), `R² тест = 0,8986`.
  - **Двухслойный перцептрон (`MLP v2.2`, слои `(64, 32)`)** — `R² тест = 0,8537`.
  - **Метод k-ближайших соседей (`KNN v2.2`, `k = 5`)** — `R² тест = 0,7702`.
- **Единое отображение цен в рублях (`₽` / `тыс. руб.`)** без использования иностранной валюты (пересчёт исходного столбца `price` по фиксированному коэффициенту `93,5`) и полная расшифровка всех сокращений (`Передний привод (FWD)`, `Задний привод (RWD)`, `Полный привод (4WD)`, `куб. дюймы`, `фунты`, `миль/галлон (MPG)`).
- **Ограничители ввода (`clamp_car_features`) и сброс (`Reset`):** синхронизированный ввод «ползунок + числовое поле» с жёсткой проверкой физических диапазонов датасета и кнопкой сброса параметров.
- **Вероятность цены:** оценка попадания реальной рыночной цены в коридор **±15%** от прогноза с выводом самого коридора в `₽`, ограничителем шкалы **5%–99%** и тремя уровнями надёжности (`80–99%` высокая, `60–79%` средняя, `5–59%` низкая).
- **Веб-приложение (`Streamlit`):** 5 разделов — «Прогнозирование», «Пресеты авто», «Аналитика (OLAP)», «История (SQLite)» и «Справка о проекте» (инструкция, словарь параметров с ограничителями, методика вероятности и реестр версий моделей).
- **Telegram-бот (`aiogram 3`):** пошаговый FSM-расчёт с ограничителями, выбор модели `v2.2` с качеством, готовые пресеты, раздел «Справка» (`/help`), история и статистика, а также QR-код быстрого доступа (`reports/figures/bot_qr_code.png`).
- **Локальное логирование в SQLite (`predictions.db`):** хранение и аудит истории расчётов из веб-приложения и Telegram-бота.
- **Перекрёстная проверка в Loginom Community 7.4.2:** сценарий из 9 узлов (`loginom/kursovaya.lgp`) с встроенными визуализаторами («Отчет по регрессии» и «Статистика»).

## Структура проекта

- `src/` — исходный код приложения:
  - `src/config/` — пути, метаданные (`MODEL_VERSION = "v2.2"`), русские расшифровки признаков, пресеты автомобилей, эталонные метрики Loginom.
  - `src/data/` — загрузка, очистка марок/признаков, ограничитель-валидатор (`clamp_car_features`) и пайплайн предобработки (`CarDataPreprocessor`, 69 признаков).
  - `src/models/` — обучение 4 моделей (`Random Forest`, `Ridge`, `MLP`, `KNN`), инференс (`ModelService`), расчёт 95% доверительного интервала, вероятности цены (±15%) и рыночной сегментации.
  - `src/analytics/` — построение EDA-графиков, корреляционной матрицы, OLAP-срезов и сравнения моделей (в рублях, 300 DPI).
  - `src/storage/` — локальная база SQLite (`predictions.db`) для логирования истории прогнозов.
  - `src/web/` — веб-интерфейс на `Streamlit` (`predict_page.py`, `presets_page.py`, `olap_page.py`, `history_page.py`, `help_page.py`).
  - `src/bot/` — Telegram-бот на `aiogram 3` (`app.py`, `handlers.py`, `keyboards.py`, `formatting.py`, `states.py`).
- `scripts/` — скрипты автоматизации:
  - `scripts/generate_visuals.py` — генерация всех графиков, переделанных схем архитектуры/алгоритма и QR-кода бота.
  - `scripts/capture_screenshots.py` — захват скриншотов веб-приложения и Telegram-бота через Playwright.
  - `scripts/create_presentation.py` — сборка итоговой презентации (20 слайдов).
  - `scripts/update_report.py` — обновление пояснительной записки `.docx`.
- `tests/` — **35 модульных автотестов (`pytest`)** по всем 6 компонентам системы.
- `data/` — исходный датасет `CarPrice_Assignment.csv`, обработанная таблица и словарь признаков.
- `models/` — обученные модели (`.joblib`), препроцессор и версионированные метаданные (`metadata.json`).
- `reports/` — метрики (`metrics.json`) и графики/схемы/скриншоты (`reports/figures/`).
- `screenshots/` — скриншоты веб-интерфейса, Telegram-бота, QR-код и визуализаторы Loginom.
- `loginom/` — пакет сценария `kursovaya.lgp` (9 узлов) для Loginom Community 7.4.2 (см. [loginom/README.md](loginom/README.md)).
- `train_models.py` — полный цикл подготовки данных, построения графиков и обучения моделей.
- `run_web.py` — запуск веб-интерфейса (`Streamlit`).
- `run_bot.py` — запуск Telegram-бота (`aiogram 3`).
- `Пояснительная_записка_Груздев_А_А.docx`, `Презентация_Груздев_А_А.pptx` — итоговые материалы к защите курсовой работы.

## Быстрый старт

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Обучение моделей и генерация графиков:**
   ```bash
   python train_models.py
   python scripts/generate_visuals.py
   ```

3. **Запуск веб-интерфейса (Streamlit):**
   ```bash
   python run_web.py
   ```

4. **Запуск Telegram-бота (aiogram 3):**
   ```bash
   set BOT_TOKEN=ваш_токен_от_BotFather
   python run_bot.py
   ```

5. **Запуск автотестов (35 тестов):**
   ```bash
   python -m pytest -v
   ```
